DevOps Практическая работа П04: Деплой веб-сервера с помощью Ansible
📝 Описание
В данной работе демонстрируется автоматизация развертывания веб-сервера Nginx с помощью Ansible.

🎯 Цель работы
Установка и настройка Ansible
Создание файла инвентаризации
Написание Ansible playbook
Автоматизация установки Nginx
Деплой статического контента
📁 Структура репозитория
ansible-p04/ ├── README.md # Описание проекта ├── playbooks/ │ └── playbook.yml # Основной плейбук ├── inventory/ │ └── inventory.ini # Файл инвентаризации хостов ├── files/ │ └── index.html # Шаблон индексной страницы └── screenshots/ # Скриншоты выполнения

🚀 Быстрый старт
Требования
Ansible 2.9+
Python 3
SSH-доступ к целевым хостам
Установка зависимостей
sudo apt update
sudo apt install ansible -y
